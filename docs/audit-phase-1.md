# Phase 1 — تدقيق النموذج الأولي (v23)

هذا التقرير هو سبب وجود هذا المستودع. النموذج الأولي `docs/prototype-v23.html`
ملف واحد بـ 2,995 سطر (216 KB): CSS ‎10–538‎، HTML ‎540–1281‎، JS ‎1282–2992‎.

## الخلاصة

نموذج أولي **عالي الجودة بصرياً وتجريبياً**: التصميم متسق، RTL أصلي، الوضع
الليلي نظيف، التجاوب جيد (21 media query)، والأكاديمية والفرق فيهما منطق حقيقي
لا واجهات فارغة. لكنه **ليس قاعدة يمكن البناء عليها**: لا بيانات، لا مصادقة، لا
صلاحيات، لا حفظ.

## ما وجدناه

| # | المشكلة | الأثر |
|---|---|---|
| 1 | لا Backend ولا Database — كل شيء مصفوفات JS في الذاكرة | إعادة التحميل تمسح كل التقدّم |
| 2 | لا كيان `User`؛ الاسم و`TMU-X8K4P2R7` مكتوبان يدوياً في 6+ أماكن | مبدأ «هوية واحدة» غير منفّذ |
| 3 | `submitLogin` = `showToast` + `go('home')`؛ الفصل بين الصفحة العامة والتطبيق **CSS فقط** | روابط الفوتر تتخطى «تسجيل الدخول» تماماً |
| 4 | **نظاما تقدّم متوازيان**: `lesson.status` (ضغطة زر) يحرّك الشهادات، و`assignment.status` يحرّك XP — منفصلان | شهادة مسار كامل بصفر تسليمات وصفر تقييم |
| 5 | `scoreToXP = score × 10` → تكليف واحد = 900 XP، وأعلى رتبة على بُعد 9 تكليفات | مقياس بلا معنى، ويناقض قاعدة «أرقام صغيرة» |
| 6 | XP يأتي من التقييم فقط — لا من الدروس ولا الفرق ولا الجلسات | مصادر النقاط المعلنة غير موجودة |
| 7 | «تعديل وإعادة إرسال» **يمسح** التقييم السابق | لا Re-evaluation قابل للتتبع |
| 8 | الشهادة: `window.print()` بلا Certificate ID ولا QR ولا صفحة تحقق ولا TechMood ID | أبعد ميزة عن المواصفات |
| 9 | `bookMentorSession` = 3 أسطر تدفع الحجز إلى `upcoming` مباشرة | لا حالات، لا توفر، لا قاعدة 3 أيام، لا قبول منتور |
| 10 | لا نظام دفع إطلاقاً؛ المحفظة أرقام ثابتة | صفر ذكر لـ BoP / PalPay / Jawwal Pay / إثبات الدفع |
| 11 | أسعار المنتورز `15/18/20/22/25/35$` نصوص حرة | جدول L1–L6 (15/25/35/50/75/100) غير منفّذ، و18/20/22 لا وجود لها فيه |
| 12 | `switchPersona()` تعرض Toast فقط | محوّل الأدوار زينة؛ المنصة كلها بمنظور الطالب |
| 13 | لوحة الإدارة مرئية للجميع بلا شرط | 13 من 14 قائمة إدارية مفقودة، وأهمها التحقق اليدوي من الدفع |
| 14 | نص المستخدم يدخل `innerHTML` بلا تهريب (الدردشة، المهام، الروابط) | HTML Injection يتحول إلى XSS فور مشاركة البيانات |
| 15 | 123 معالج `onclick` مضمّن مع حقن قيم داخل نصوص JS | اسم فيه `'` يكسر الزر؛ ويمنع أي CSP آمن |
| 16 | `pickTrend()` و`Math.random()` في الدرجات | ترتيب يتغير كل رندر؛ نتائج غير قابلة للاختبار |
| 17 | لا Router ولا URL state | لا deep links، لا زر رجوع، لا مشاركة رابط |
| 18 | 3 سمات `aria` في الملف كله؛ `div` قابلة للنقر؛ لا حصر تركيز في المودال | وصولية ضعيفة |
| 19 | 9 دوال تسليم/تقييم/تعديل شبه متطابقة؛ فوتر مكرر؛ 3 اصطلاحات لمفاتيح localStorage | تكرار يصعّب التطوير |
| 20 | لا منع للروابط والصور في الدردشة رغم أنها قاعدة معلنة | مخالفة لقواعد المنتج |

## ماذا فعلنا بها

كل بند أعلاه صار قيداً في قاعدة البيانات وله اختبار في `scripts/test-rules.sql`.
راجع قسم «The rules this codebase exists to enforce» في `README.md`، و
`docs/architecture.md` لتفاصيل النموذج والصلاحيات.

ما تم الحفاظ عليه كما هو: الهوية البصرية كاملة، الاتجاه RTL، الوضع الليلي،
ومحتوى الأكاديمية بالكامل (6 مسارات، 18 دورة، 36 درساً بمددها الأصلية، و18 مهمة
تطبيقية).
